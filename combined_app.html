About This Project

AI Fashion Stylist & 3D Virtual Try-On Studio combines computer-vision body/face analysis, a StyleMate SQLite database (stylemate.db), personalized garment recommendations, and a real-time Three.js 3D human avatar — all in one integrated platform. Upload your photo, get AI-driven style insights, and try outfits on a photorealistic 3D model instantly.

🐍 Python 3 + Flask 🗄️ SQLite + SQLAlchemy 🌐 Flask-CORS 🎮 Three.js r128 🧊 GLTFLoader 🤖 NumPy + Pillow AI 📓 Google Colab
